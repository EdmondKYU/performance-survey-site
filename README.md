# 通用考核调研平台

这是一个可直接运行的本地网站原型，包含：

- 负责人通过后台选择问卷模板，创建考核事项并生成专属二维码
- 评价人扫码进入问卷，按模板维度评分
- 核算时剔除最高分和最低分，再计算绩效分
- 每个模板可拥有自己的维度、满分、KPI 档位和权重
- 负责人注册、登录、查看自己的问卷和绩效数据
- 管理员登录、查看全部负责人、问卷、评价明细与导出 CSV

当前内置模板：

- 课程分享满意度调研：5 个维度各 20 分，总分 100 分，KPI 权重 30%
- 跨部门协同满意度调研：6 个维度各 20 分，总分 120 分，KPI 权重 20%
- 工作配合度满意度调研：6 个维度各 20 分，总分 120 分，KPI 权重 20%

## 启动

```bash
node server.js
```

默认访问：

```text
http://localhost:4768
```

## 生产发布

这个网站会把账号、课程、问卷结果保存到 JSON 数据文件。发布到云平台时，请配置持久化数据目录：

```text
DATA_DIR=/data
```

如果使用 Render、Railway、Fly.io 或自己的云服务器，请把持久化磁盘/Volume 挂载到 `/data`。项目也包含 `Dockerfile`，可直接用容器方式部署。

管理员默认账号：

```text
admin@example.com
admin123456
```

也可以通过环境变量修改：

```bash
ADMIN_EMAIL=your@email.com ADMIN_PASSWORD=your-password node server.js
```

## 扫码说明

负责人登录后选择模板创建问卷，后台会生成问卷链接和二维码。  
如果需要手机扫码访问，请用同一局域网下的电脑 IP 打开网站，例如：

```text
http://192.168.1.10:4768
```

这样生成的二维码才会指向手机可访问的地址。生产使用建议部署到公网域名。
