# 课程分享满意度调研与绩效核算网站

这是一个可直接运行的本地网站原型，包含：

- 学员通过讲师专属二维码进入问卷
- 5 个维度各 20 分，总分 100 分
- 核算时剔除最高分和最低分，再计算平均满意度
- 按图片 KPI 档位换算绩效分，并计算 30% 权重得分
- 讲师注册、登录、创建课程、查看自己的数据
- 管理员登录、查看全部讲师、课程、问卷与导出 CSV

## 启动

```bash
node server.js
```

默认访问：

```text
http://localhost:4768
```

## 生产发布

这个网站会把账号、课程、问卷结果保存到 JSON 数据文件。发布到云平台时，请配置持久化数据目录：

```text
DATA_DIR=/data
```

如果使用 Render、Railway、Fly.io 或自己的云服务器，请把持久化磁盘/Volume 挂载到 `/data`。项目也包含 `Dockerfile`，可直接用容器方式部署。

管理员默认账号：

```text
admin@example.com
admin123456
```

也可以通过环境变量修改：

```bash
ADMIN_EMAIL=your@email.com ADMIN_PASSWORD=your-password node server.js
```

## 扫码说明

讲师登录后创建课程，后台会生成课程问卷链接和二维码。  
如果需要手机扫码访问，请用同一局域网下的电脑 IP 打开网站，例如：

```text
http://192.168.1.10:4768
```

这样生成的二维码才会指向手机可访问的地址。生产使用建议部署到公网域名。
